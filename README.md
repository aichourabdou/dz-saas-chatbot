# 🤖 DZ SaaS Chatbot

A fast and interactive AI Chatbot designed for SaaS applications, powered by **Groq API** and built using **Gradio** and **Python**.

## 🚀 Features
- Fast response generation using Groq LLM infrastructure.
- User-friendly web interface powered by Gradio.
- Lightweight and easy to deploy.

## 🛠️ Tech Stack
- **Language:** Python
- **UI Framework:** Gradio
- **API:** Groq Cloud API
